## 📌 About This Repository

Welcome! This repository serves as a personal laboratory and public showcase for my journey through **Machine Learning**, **Data Science**, and **Data Analysis**. 

Here you'll find:
* 📓 **Jupyter Notebooks** detailing step-by-step data analysis & model building.
* 🧹 **Data Preprocessing & Feature Engineering** (Scaling, Encoding, Handling Missing Values).
* 📊 **EDA & Data Visualizations** uncovering hidden patterns.
* 🤖 **Predictive Models & Algorithms** implemented from scratch and via Scikit-Learn.
